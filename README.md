# Universal Sound Converter 🚀

[![Built with Gemini](https://shields.io)](https://google.com)

A sleek, lightweight desktop software built in Python using **CustomTkinter** that easily batch-converts video and audio tracks natively across various formats.

## Features 🪄
- **Persistent Memory**: Remembers your preferred light/dark theme settings automatically between launches.
- **Batch Processing**: Staged queues process multiple selections consecutively.
- **Smart Counter Suffixing**: Automatically prevents overwriting older tracks by naming duplicates sequentially `(1)`, `(2)`, etc.
- **Universal Matrix Routing**:
  - `MP4 to MP3`: Fast structural audio extraction from video container fields.
  - `WAV, FLAC, M4A to MP3`: High speed down-sampling matrix options.
  - `Cross-Codec Encoding`: Convert directly between open source audio containers like **WAV to FLAC**.

## Installation & Usage 🛠️

Install GIT if you don't have it.  -Link  --->  https://git-scm.com/install/windows

1. **Clone this repository:**
   ```bash
    git clone https://github.com/Pasindu-vsc/Universal-Sound-Converter.git
   ```

2. **Navigate into the cloned folder:**
   *(Crucial Step: You must move your terminal inside the project directory for the installation scripts to work!)*
   ```bash
   cd Universal-Sound-Converter
   ```

3. **Install requirements:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Launch the software:**
   ```bash
   python sound_converter.py
   ```
